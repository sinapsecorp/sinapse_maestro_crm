# Frontend (Vite + React)

## Desenvolvimento

- `npm run dev` inicia o Vite em `http://localhost:5173`
- A API deve estar em `http://localhost:8000`

## Novas Rotas de Modelos

- `/templates` listagem de modelos
- `/templates/new` editor drag-and-drop
- `/templates/:id/edit` edição de modelo existente

O editor utiliza GrapesJS com blocos inspirados no RD Station (Conteúdo, Mídia, Interativos, Estrutura, Avançado e Linhas) e painel de Configuração (largura, alinhamento, cores, fonte, cor de link e preheader).
